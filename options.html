Source Lens

웹페이지의 이미지·영상·SVG 원본 주소를 찾아 보여주고 저장합니다.

사용법

  • 확장 아이콘 클릭 → 이 페이지의 이미지·영상·SVG 목록. 검색·크기 필터·체크박스로 골라서 저장 / ZIP / URL 복사.
  • 페이지에서 크게 보기 (기본 단축키 Alt+Shift+D) → 페이지 위에 큰 패널이 열립니다.
  • Alt(⌥)+클릭 → 클릭한 이미지·영상·SVG 하나만 분석. 마우스를 올리고 Alt+Shift+S 를 눌러도 됩니다.
  • 우클릭 메뉴 → 「이 요소의 원본 주소 분석」 / 「이 페이지 미디어 모두 보기」.
  • 패널 단축키: 1–4 탭 이동, / 검색, S 저장, C 복사, 크게 보기에서 ← →, Esc 닫기.

설정

알아두기

  • 「만료 주소」 표시가 있는 링크(인스타그램·페이스북 등)는 시간이 지나면 열리지 않습니다. 바로 저장하세요.
  • ZIP은 한 번에 최대 40개까지 묶습니다. 인스타그램 CDN처럼 막힌 곳은 하나씩 저장됩니다.
  • 유튜브·넷플릭스 등 보호된 영상은 저장하지 않습니다. DRM 우회, 로그인 보호 해제, 서명 위조는 하지 않습니다.
  • 분석은 현재 탭 안에서만 이뤄지고 외부 서버로 아무것도 보내지 않습니다.
